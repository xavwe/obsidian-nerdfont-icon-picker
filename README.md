# NerdFont Icon Picker

[![Downloads](https://img.shields.io/github/downloads/xavwe/obsidian-nerdfont-icon-picker/total?style=flat-square)](https://github.com/xavwe/obsidian-nerdfont-icon-picker/releases)

The **NerdFont Icon Picker** is a plugin for [Obsidian](https://obsidian.md/). It adds an easy-to-use [Nerd Font](https://github.com/ryanoasis/nerd-fonts) icon picker to Obsidian. You can assign a hotkey for quick access.

![](.github/assets/screenshot.png)


## Getting Started
1. Install from Obsidian Plugin Store: [NerdFont Icon Picker](https://community.obsidian.md/plugins/nerdfont-icon-picker)
2. Change `Settings > Appearance > Font > Interface Font` and `Settings > Appearance > Font > Text Font` to a NerdFont. Make sure it is installed on you system. For mobile use [Custom Font Loader](https://github.com/pourmand1376/obsidian-custom-font).
